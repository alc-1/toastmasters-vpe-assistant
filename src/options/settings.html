Demo / mock mode

When enabled, "Extract Basecamp data" and "Extract EasySpeak data" return built-in demo data instead of contacting Basecamp/EasySpeak — no login, no tab opened. Useful for a demo. Any real data already extracted is left untouched until the next extraction while this is on overwrites it.

EasySpeak server

EasySpeak runs as separate regional deployments. Choose which one to load data from.
This only affects future loadings, so run "Extract EasySpeak data" again after switching.
