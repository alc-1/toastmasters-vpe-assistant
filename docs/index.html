Toastmasters VPE Assistant

A Chrome extension that brings your club's Basecamp and EasySpeak Pathways progress together in one place — so a VPE doesn't have to cross-check two systems by hand.

What it does

Basecamp Toastmasters and EasySpeak track the same members' Pathways progress but don't talk to each other. This extension extracts data from both, matches members, clubs, and paths across them, and shows exactly where they agree, where they disagree, and who's ready to level up next.

Requirements

  • A computer — this is a browser extension, so it won't work on a phone or tablet.
  • A Chromium-based browser: Google Chrome, Microsoft Edge, Brave, Opera, Vivaldi, or Arc.
  • Officer access at a Toastmasters club — the extension only pulls data for clubs where you're an officer in Basecamp/EasySpeak; a regular member account won't have enough access.

Install

Not on the Chrome Web Store yet — install it manually from the latest release:

  1. Download the latest release and unzip it.
  2. Open chrome://extensions in Chrome — Chrome doesn't allow web pages to link directly to it, but you can and paste it into the address bar.
  3. Enable Developer mode (top right).
  4. Click Load unpacked and select the unzipped folder.
